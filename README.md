## 五、線路科普三分鐘：CN2 GT、CN2 GIA、CN2 GIA-E 到底差在哪

很多人被這幾個名詞繞暈，其實層級關係很清晰：

- **普通 163 線路**：電信基礎骨幹網，便宜但晚高峰容易擁堵，國際出口體驗一般。
- **CN2 GT**：電信 CN2 線路的「入門款」，去程走 CN2、回程可能走 163，比普通線路順一些，但晚高峰仍會抖。
- **CN2 GIA**：CN2 線路的「高級款」，去程回程都走 CN2 GIA，三網都優化，穩定性大幅提升。
- **CN2 GIA-E（E-COMMERCE）**：在 CN2 GIA 基礎上加了電商級保障，帶寬更大（2.5Gbps 起），機房選擇更多，是搬瓦工最主推的線路。
- **香港/日本 CN2 GIA**：直連中國的 CN2 GIA 節點，延遲最低，但價格也最貴。

一句話總結：**預算夠就上 GIA-E，預算緊就 CN2 GT 入門，延遲敏感就香港/日本，千萬別圖便宜買 KVM 然後硬遷 CN2 機房——流量會被砍到 1/3，得不償失。**
